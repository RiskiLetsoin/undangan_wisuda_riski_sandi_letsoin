# Musik undangan

Lagu mengikuti warna tema:

1. `audio1.mp3` — Biru navy gelap
2. `audio2.mp3` — Green Hunter
3. `audio3.mp3` — Abu-abu
4. `audio4.mp3` — Merah maron
5. `audio5.mp3` — Hitam
6. `audio6.mp3` — Ungu
7. `audio7.mp3` — Kuning

Tema awal undangan adalah Hitam. Musik mulai saat tamu menekan tombol "Buka Undangan" pada sampul, sehingga pemutaran dimulai melalui tindakan pengguna dan tidak bergantung pada autoplay halaman. Ikon musik dapat digunakan untuk menjeda atau melanjutkan lagu.
