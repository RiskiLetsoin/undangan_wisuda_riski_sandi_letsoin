# Musik undangan

Undangan menggunakan `audio.m4a` sebagai musik pengiring dan mencoba memutarnya otomatis secara berulang. Ikon musik di sudut layar berfungsi untuk jeda dan melanjutkan pemutaran. Browser ponsel dapat membatasi autoplay bersuara; jika musik belum mulai, tamu dapat menekan ikon tersebut.
