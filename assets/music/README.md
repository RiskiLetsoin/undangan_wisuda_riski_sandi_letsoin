# Musik undangan

Lagu mengikuti warna tema:

1. `audio1.mp3` — Biru navy gelap
2. `audio2.mp3` — Green Hunter
3. `audio3.mp3` — Abu-abu
4. `audio4.mp3` — Merah maron
5. `audio5.mp3` — Hitam

Audio1, audio2, dan audio5 sudah dikonversi ke MP3 standar agar dapat diputar di browser. Berkas sumber lama `audio1.m4a` tetap disimpan, tetapi tidak digunakan oleh undangan. Ganti tema akan mengganti lagu; pemutaran berulang tetap aktif. Ikon musik berfungsi untuk jeda dan melanjutkan pemutaran. Browser ponsel dapat membatasi autoplay bersuara; jika musik belum mulai, tamu dapat menekan ikon tersebut.
